Execute via API

Same endpoints the UI uses. Authenticate with an API key (Admin → API Keys) as Authorization: Bearer qbit_….

  1. POST /api/v1/scrapers/{{ actor.id }}/jobs — validate + enqueue a run
  2. GET /api/v1/scrape-jobs/{job_id} — poll status & counters
  3. GET /api/v1/scrape-jobs/{job_id}/results — paged normalized records
  4. GET /api/v1/scrape-jobs/{job_id}/results/export?format=xlsx — download
curl -sS -X POST https://your-qbit-host/api/v1/scrapers/{{ actor.id }}/jobs \
  -H "Authorization: Bearer qbit_YOUR_KEY" -H "Content-Type: application/json" \
  -d '{"input": {{ actor.input_example | tojson if actor.input_example else '{}' }}, "config": {"max_records": 100}}'
